# Academy Website

A Django-based academy management website designed to manage students, teachers, courses, classes, admissions, and attendance through a web-based system.

## Features

* Student registration and management
* Teacher management
* Course and subject management
* Class management
* Student admissions
* Student enrollment
* Attendance management
* Teacher and student dashboards
* Admin dashboard
* Contact information management
* "Why Choose Us" section
* Public course and teacher information pages
* User authentication and role-based access

## Technologies Used

* Python
* Django
* HTML
* CSS
* SQLite
* Font Awesome

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/dri574069-beep/Academy-Website.git
cd Academy-Website
```

### 2. Install Django

```bash
pip install django
```

### 3. Run migrations

```bash
python manage.py migrate
```

### 4. Start the development server

```bash
python manage.py runserver
```

Then open the local development address shown in the terminal.

## Note

This project is intended as an academy management website and portfolio project. The local SQLite database is excluded from the repository using `.gitignore`.
